# Titis Surya — Portfolio

Website portfolio statis berbasis HTML/CSS/JavaScript.

## Menjalankan
Buka `index.html` di browser.

## Publish gratis
Upload seluruh isi folder ini ke repository GitHub, lalu aktifkan:
Settings → Pages → Deploy from a branch → main / root.

Setelah aktif, GitHub akan memberikan URL publik untuk dibagikan ke recruiter.
